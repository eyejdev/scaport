Guía de Uso & Conceptos Clave (scaport)

Aprende a interpretar estados, resolver bloqueos y usar atajos

👁️ ¿Qué es y qué hace el "Modo Monitor / Watch Daemon"?

scaport cuenta con dos niveles de supervisión:

  • 1. Descubrimiento Pasivo (SSE): Lee la tabla de sockets del Sistema Operativo en tiempo real sin enviar tráfico de red. Consume menos de 0.1% de CPU y está activo por defecto.
  • 2. Watch Daemon Activo (Botón 👁️): Además de leer sockets, envía peticiones HTTP periódicas para comprobar si el servidor está respondiendo o congelado en bucle infinito (deadlock).

🩺 ¿Qué significa la columna "Health"?

Evalúa la disponibilidad real del servidor web realizando peticiones HTTP asíncronas:

⚪ Idle: Socket abierto a nivel de OS, en espera de healthcheck o servicio no-HTTP.
🟢 200 OK: Servicio web activo y respondiendo exitosamente.
🟡 4xx/5xx: El servidor responde pero devuelve código de error o ruta raíz 404.
🔴 Unhealthy / Err: Timeout o conexión rechazada. Posible proceso colgado.

🔄 ¿Qué es "Hot-Cycle" (Reinicio Rápido)?

Si tu servidor (Vite, Next.js, FastAPI, Go) se congela o no detecta cambios, el botón Restart (Hot-Cycle) mata el proceso y lo vuelve a lanzar automáticamente en su mismo directorio de trabajo (CWD) con sus argumentos originales.

🛑 ¿Se pueden cerrar los procesos sin consumo con el botón Kill?

Algunos puertos en el rango alto (49000+) muestran - MB o unknown porque pertenecen a servicios del sistema donde el OS restringe la telemetría a usuarios estándar:

  • ✅ Procesos de Usuario en Segundo Plano: Si el puerto fue abierto por una app de usuario (Discord, workers, etc.), al pulsar Kill se finaliza y el puerto se libera de inmediato.
  • 🛡️ Procesos del Kernel (PID 4, System): scaport muestra la insignia Shield y bloquea el botón para evitar inestabilidad en tu sistema operativo.
  • 🔒 Servicios Protegidos por Windows: Si un servicio requiere permisos de administrador y se intenta matar, Windows denegará el acceso y scaport te informará con un aviso seguro.

🛡️ Acciones Recomendadas ante Bloqueos

  • Error de Puerto Ocupado (EADDRINUSE): Usa el botón Kill para liberar el puerto inmediatamente.
  • Procesos del Sistema (PID 4, System): scaport los protege con su escudo para evitar inestabilidad en tu OS.
  • Filtro ⚡ Dev Only: Oculta sockets del sistema y muestra únicamente proyectos de desarrollo reconocidos.

⌨️ Comandos CLI Útiles

scaport check 3000 8080 # Anti-colisiones para package.json/CI

scaport watch 3000 5173 # Vigilante de salud HTTP en consola

scaport kill 3000 # Mata proceso en el puerto :3000

scaport --md > report.md # Exporta auditoría en Markdown
